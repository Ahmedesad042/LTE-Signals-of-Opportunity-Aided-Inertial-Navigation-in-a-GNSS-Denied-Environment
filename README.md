# LTE-Signals-of-Opportunity-Aided-Inertial-Navigation-in-a-GNSS-Denied-Environment

This project is a MATLAB proof-of-concept simulation of aircraft localization using LTE signals of opportunity and inertial navigation.

LTE base stations are mapped while GNSS is available. During GNSS outages, inter-receiver time differences of arrival (TDOA) provide bearings for position estimation, which is fused with inertial navigation using an Extended Kalman Filter (EKF).

Developed as an internship project at ASELSAN. The simulation considers simplified 2D conditions.
